# Darbandi FDK Reconstruction GUI

This folder contains the Python package and app entry point for Darbandi FDK Reconstruction.

Run from the repository root:

```powershell
python fdk-engine.py
```

Run the self-test:

```powershell
python microct_tigre_gui/main.py --self-test
```

For complete installation and user instructions, see the root [USER_MANUAL.md](../USER_MANUAL.md).
